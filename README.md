## ✨ About This Project

This is my **personal portfolio website** — built to showcase who I am, what I've built, and what I'm learning as a Frontend Web Developer and B.Tech CSE student. It's fully responsive, animated, and deployed live.

> 🔗 **Live Site:** [samir-portfolio-mu.vercel.app](https://samir-portfolio-mu.vercel.app/)

<br/>

## 🚀 Features

- 🎬 Smooth GSAP + AOS scroll animations throughout
- 📱 Fully responsive across mobile, tablet & desktop
- 🧩 Sections: Home · About · Skills · Portfolio · Certifications · Contact
- 📂 Live project showcase with direct links to each deployed app
- 📜 Downloadable resume (CV) button
- 📧 Working contact form (powered by FormSubmit — messages land straight in my inbox)
- 🎓 Certifications & internships displayed with real certificate images
- 🌗 One-page smooth-scroll navigation with active section highlighting
